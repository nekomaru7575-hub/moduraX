## 目的

チャット欄に入力している最中に、そのコマのチャットパレットから部分一致するフレーズを
予測変換のように提示し、クリックで入力欄へ反映できるようにする（送信はしない）。

## 受入条件

- [ ] チャット欄（`commandInput`）の直下に、候補を並べるリストの DOM が追加されている
- [ ] 候補に出すのは、**チャット欄で選択中のコマの名前と一致する名前を持つチャットパレットタブ**の
      フレーズだけ。他のタブのフレーズは出さない
- [ ] チャット欄でコマが選択されていない（「（選択なし）」）ときは、候補を出さない
- [ ] 入力が空文字のときは候補を出さない
- [ ] 一致判定は「フレーズが入力文字列を含む」こと。英字の大文字・小文字は区別しない
- [ ] 候補の表示件数は最大 8 件
- [ ] 一致するフレーズが 0 件のときは、候補リストを表示しない（前回の候補が残らない）
- [ ] 候補をクリックすると、チャット欄の内容がそのフレーズで**全置換**される
- [ ] 候補をクリックしても**送信されない**（`sendBtn` のクリックや送信処理を呼ばない）
- [ ] クリック後は候補リストが閉じ、チャット欄にフォーカスが戻る
- [ ] Escape キーで候補リストが閉じる
- [ ] フレーズは `textContent` で描画する。`innerHTML` にフレーズを埋め込まない
      （フレーズはユーザー入力であり、そのまま HTML として解釈させない）
- [ ] 既存のチャット送信、チャットパレットの表示・編集・保存の挙動が変わらない

## 実装メモ

着手前に、以下を**調べてから**実装すること。推測で書かないこと。

- チャットパレットの状態の読み出しは `loadChatPaletteState`、
  フレーズ行への分解は `parseChatPaletteLines`（どちらも `js/chat-palette.js`）。
  タブが持つ「名前」フィールドの実際のキー名を確認すること。
- チャット欄の入力欄と送信ボタンは `commandInput` / `sendBtn`。
  配線は `js/main.js` にある。送信処理そのものは変更しないこと。
- **チャット欄で参照コマを選ぶ `<select>` がどれかを特定すること。** 選択値はコマIDで、
  タブの「名前」はコマ名なので、ID から名前を引く必要がある。コマの情報は
  `js/game-store.js` から取得できる。
- 候補リストの見た目は、既存のチャットパレット周りの CSS に合わせる。
  新しい色やフォントを勝手に定義しない。
- 候補リストは、入力欄の内容が変わるたびに作り直してよい（件数が最大8件と少ないため）。
