## 目的

DX3プラグインの能力・技能値表示ボックスに「判定をコピー」ボタンを追加する。
押すと、そのコマで技能値が設定されているすべての技能について、汎用判定のコマンドを
1行1件でまとめてクリップボードへコピーできるようにする。

## 受入条件

- [ ] 能力・技能値表示ボックスの UI に「判定をコピー」というラベルのボタンが1つ追加されている
- [ ] ボタン押下で、クリップボードへテキストが書き込まれる。書き込み手段とコピー成否のフィードバック表示は `js/parameters/dx3-combo-box.js` の既存コピー処理と同じ方式を使っている
- [ ] コピーされるテキストは、**技能値が設定されている技能につき1行**。値が未設定の技能は行を出さない
- [ ] 各行の判定コマンドの書式は、同ボックスの既存「判定」操作が生成する書式と**文字列として同一**である（同じ技能・同じ値なら1文字も違わない）
- [ ] 技能に対応する能力値は `DX3_ABILITY_SKILL_GROUPS` の対応関係から解決している。技能名から能力値への対応表を新しくハードコードしていない
- [ ] 能力値単体の判定（技能を伴わない素の能力値判定）の行を含まない
- [ ] 技能値が1つも設定されていない場合に例外を投げず、ボタンを押しても壊れない
- [ ] 既存の「判定」ボタンの挙動・出力が変わっていない

## 実装メモ

- 既存のクリップボードコピーの実装が `js/parameters/dx3-combo-box.js` にある。`navigator.clipboard` の呼び方、失敗時の扱い、コピー完了の見せ方はそれに合わせること。**新しい方式を発明しない。**
- 判定の書式は**必ずコードを読んで確認してから**組み立てる。推測で書式を作らない。既存の書式生成処理が関数として切り出されているなら、それを呼び出して再利用する（同じ書式を2箇所に書かない）。
- `DX3_ABILITY_SKILL_GROUPS` は `js/parameters/dx3-ability-box.js` と `js/parameters/dx3-combo-box.js` の両方から参照されている。どちらが定義元かを確認してから使うこと。
- 「技能値が設定されている」の判定基準（空文字・0・未定義のどれを未設定とみなすか）は、同ボックスが既存の技能値表示・判定で使っている基準に合わせる。新しい基準を作らない。
- 専門化を持つ技能（`《運転:バイク》` のような表記）がある場合、既存の「判定」がその表記をどう扱っているかに従う。
- ALLOW に4ファイル挙げているが、これは NEED-ALLOW の往復を避けるための余裕であって、4つとも触れという意味ではない。**実際の変更は必要最小限にとどめること。**
