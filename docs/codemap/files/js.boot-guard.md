## 役割

<!-- prose:role -->
ページに必要なJSかCSSが1本でも届かなかったときに、利用者へ分かる形で知らせる見張り。このアプリはESモジュールで100本近いJSを並列に読むため、1本落ちるとそこから先が全部止まるが、**画面そのものは出てしまう**——実測すると盤面もチャット欄も描かれ、通信状態だけが「● 接続中...」のまま永久に止まり、エラーは開発者コンソールにしか出ない。利用者からは「開いたのに、いつまでも繋がらない部屋」に見え、**再読み込みで直ることが分からない**のが一番の問題だった（本番で2回発生。サーバー再起動の瞬間に当たった1本が520で落ちた）。**古典スクリプトとしてheadの先頭で読むこと**が要件：`type="module"` は必ず遅延実行されるので、moduleにすると見張りを始める前に他の読み込みが失敗しうる。そのため他のどのファイルにも依存しない（依存したら本末転倒）。画像の失敗では出さない——コマの絵が1枚欠けただけで全画面警告を出す方が事故になるため、SCRIPTとstylesheetのLINKだけを対象にしている。[[sw]] がJS・CSSをキャッシュしないのは意図的な判断（ファイル名にハッシュが無いため）なので、そちらでは肩代わりしない。
