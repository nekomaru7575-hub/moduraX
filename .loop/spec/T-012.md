## 目的

T-011 で入れたチャットログのタイムスタンプを、実機確認の結果を受けて2点直す。

1. タイムスタンプの表示位置を、ログ1行の**先頭から末尾へ**移す。
2. **カレントチャット欄にはタイムスタンプを出さない**（タブのログには従来どおり出す）。

## 受入条件

- [ ] 画面のタブのチャットログで、タイムスタンプが**行の末尾**に表示される。
      行の先頭（発言者名やシステムタグより前）には出ない。
- [ ] 「ログを保存」で書き出した HTML でも、タイムスタンプが**行の末尾**に表示される。
      画面と書き出しで位置が食い違っていない。
- [ ] **カレントチャット欄にはタイムスタンプが表示されない。**
      ここでいうカレントチャット欄は、タブのログ一覧とは別に、チャット入力欄の近くへ
      現在の発言を流している表示のこと（`renderMainChatMirror` が描いているもの）。
      **どの表示がそれに当たるかは実装役が現物で特定し、`NOTES:` に書くこと。**
- [ ] タブのチャットログ（`renderActiveTabLog` が描くもの）には、これまでどおり
      タイムスタンプが出る。
- [ ] 表示形式は `HH:MM:SS` のままで変えていない。
- [ ] 時刻を持たない既存のログエントリは、これまでどおり時刻欄が空のまま表示される。
      現在時刻などで埋めていない。
- [ ] 既存の表示オプション（`buildLogHtml` の `hideSystem` など）の挙動が変わっていない。
- [ ] 依存パッケージを追加していない。

## 実装メモ

- `js/main.js:1706` 付近 `buildLogHtml(entry, { hideSystem = false } = {})`
  — 画面のログ1行の HTML を組む。T-011 でここに `time` を足し、
  `headerLine`（`[systemTag, characterTag, commentTag]` を組み立てる配列）の
  **先頭**へタイムスタンプを入れた。これを末尾へ移す。
  行の「末尾」がヘッダ行の末尾なのか、ログ1行全体（本文・ダイス内訳の後ろ）の末尾なのかは、
  **実機の見た目として自然なほうを選び、`NOTES:` に書くこと。**
- `js/main.js:165` 付近
  `appendLogEntries(container, entries, fromIndex, itemClassName, buildOptions = {})`
  — 描画の共通処理。第5引数の `buildOptions` がそのまま `buildLogHtml` の第2引数へ渡る。
  **`hideSystem` と同じ流儀で「時刻を出さない」オプションを足すのが素直。**
- `js/main.js:177` 付近 `renderActiveTabLog(state)` — タブのログ。**時刻を出す側。**
- `js/main.js:208` 付近 `renderMainChatMirror(state)` — カレントチャット欄と思われる表示。
  **時刻を出さない側。** 両者が `appendLogEntries` を別々の `buildOptions` で
  呼んでいるなら、そこで出し分ければよい。
- `js/log-export.js:24` 付近 `buildEntryHtml({ character, comment, resultText, diceDetail, color, time })`
  — 書き出し HTML の1行。T-011 で `timeHtml` を `nameHtml` の直前へ入れた。これを末尾へ移す。
  戻り値は `<div class="log-line">…</div>` と、その後ろに続く `detailHtml`。
  **`detailHtml`（ダイスの内訳）との前後関係をどうしたかを `NOTES:` に書くこと。**
- 見た目の調整（余白・色）が要るなら `combined_layout.html` 内のスタイルを触ってよい。
  T-011 では画面側が `class="log-time"`、書き出し側も `class="log-time"` を使っている。
