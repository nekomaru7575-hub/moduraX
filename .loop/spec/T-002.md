# T-002: 画像未設定の盤面パネルをうっすら見えるようにする

## ALLOW

```
js/board-data-driven.js
combined_layout.html
```

## LOCAL TASKS

### js/board-data-driven.js :: applyPanelAppearance

This function is re-applied to the SAME DOM element every time the panel state changes, so every branch must reset what the other branch sets. Otherwise a stale style stays behind.

Keep every existing line of the function exactly as it is, including all existing comments (they are Japanese; reproduce them verbatim) and the existing line that resets `el.style.backgroundImage` in the no-image branch. Do not delete or rewrite any existing line.

Add exactly two lines:

1. In the branch where the panel HAS an image: add `el.style.backgroundColor = '';` so a previously set background colour is cleared.
2. In the branch where the panel has NO image: add `el.style.backgroundColor = 'rgba(255, 255, 255, 0.05)';` so an empty panel is faintly visible on the board.

Do not change anything else.

## 目的

盤面に置いたパネルのうち、画像が設定されていないものが盤面と同化して見えないため、
ごく薄い白を敷いて「そこにパネルがある」ことだけ分かるようにする。

## 受入条件

- [ ] 画像が設定されていないパネルの要素に、白の背景 `rgba(255, 255, 255, 0.05)` が適用される
- [ ] 画像が設定されているパネルには、この背景が適用されない（現状の見た目が変わらない）
- [ ] パネルの画像を設定／解除したときに、背景の有無が追従して切り替わる
      （画像を消したら薄い白が付き、設定したら消える）
- [ ] パネルのドラッグ・選択・サイズ・重なり順など、見た目以外の既存挙動が変わらない
- [ ] コマ（トークン）の見た目は変わらない。今回の対象は盤面パネルのみ

## 実装メモ

- パネルの外観適用は `js/board-data-driven.js` の `applyPanelAppearance`（450行目付近）。
  画像の有無で分岐する箇所はこの関数の中にある。
- パネルのスタイル定義は `combined_layout.html` の `.panel-object`（474〜498行目付近）。
  関数内で完結できない場合のみ、こちらにクラスを足す方針でよい。
- 「透明度95%」はユーザー確認済みで、**不透明度 0.05**（ほぼ透明）の意味。
  ほぼ白い板にはしないこと。
