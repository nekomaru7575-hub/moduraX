     ローカルLLM（無料）に回せるのは「1つの function 宣言の中で完結する変更」だけ。
     複数ファイルにまたがる配線・新規ファイル作成・アロー関数/クラスメソッドは回せない。

     書式: ### <ファイルパス> :: <関数名>
           次の行から英語で指示を書く。指示は必ず英語で書くこと
           （日本語だと同じモデルでも指示を無視して無変更を返す）。

     #### CHECK は任意。関数が自分の引数だけで完結しているときだけ付けられる。

     ファイル全体は読み込まない。モジュール変数や DOM を参照する関数に付けると
     事前確認で落ちてユニットごと失敗する。
     CHECK は「今のコードでは落ちる」内容にすること。 -->
