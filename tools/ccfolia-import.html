ココフォリアの部屋 → もじゅらXの部屋データ

ココフォリアの部屋書き出しZIPを、もじゅらXの「部屋を作る」で読み込めるJSONへ変換します。
この道具はブラウザの中だけで動きます。どこへも送信しません。

1. ZIPを選ぶ

ココフォリアの部屋メニューから書き出したZIPです。

2. 画像の焼き直し

アニメーションしている画像（アニメWebP・GIF）は、焼き直すと1コマに潰れて演出が死ぬため、 できるかぎり元のまま素通しします。上の2つは静止画にだけ効きます。 上限に収まらないぶんは、重いアニメーションから順に静止画へ潰します （どれを潰したかは下に出ます）。
形式上の限界は約93MBですが、実際に通るのはもっと小さい値です。サーバーは取り込みに ボディの約4倍のメモリを見積もって先に予約し、足りなければ読まずに断ります （server/memory-budget.js）。いくつ通るかは、もじゅらXの部屋一覧が出している 「取り込みの余裕」の値で分かります。既定の20MBは、その余裕が 30MBほどの平常時に通る大きさです。
アニメーションを残したいときは「解像度の余裕」を1.0倍まで下げてください。 静止画に使う量が減って、そのぶんアニメーションが生き残ります。

3. 変換する 



使いかた


    
  
  1. 上でZIPを選び、「変換する」→「JSONを保存する」。
    2. 
  
  2. もじゅらXの部屋一覧で「部屋を作る」を開き、部屋名を入れて、
      ファイル選択に保存したJSONを指定する。
    3. 
  
  3. 入室すると、シーンも盤面の飾りも入った状態で始まります。
    4. 




移らないもの


    
  
  • クリックでシーンが切り替わるボタンは効きません。絵としては置かれますが、
      もじゅらXのパネルにクリック動作が無いためです。シーンの切り替えはシーン一覧から行います。
    • 
  
  • 全画面の演出はコマの下に入ります。もじゅらXではパネルがコマより上へ行けません。
    • 
  
  • BGM・効果音は移りません。ココフォリアのZIPに音源の実体が入らないためです。
    • 
  
  • コマ（キャラクター）は取り込みません。もじゅらXでは各自が自分のコマを作ります。
    • 
  
  • ココフォリアの.token（部屋の資格情報）は読みません。
