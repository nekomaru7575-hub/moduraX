## 目的

DX3 プラグインの能力・技能表示ボックス内で、能力値と技能値をドロップダウンから選んで
「実行」を押すと、判定用のダイスコマンドがチャット欄に送信されるようにする。

## 受入条件

- [ ] 能力・技能表示ボックス内に、能力値ドロップダウン・技能値ドロップダウン・実行ボタンの3要素が追加されている
- [ ] 能力値ドロップダウンの選択肢は、対象キャラクターの能力値（肉体・感覚・精神・社会）から動的に生成される。ハードコードした固定リストではない
- [ ] 技能値ドロップダウンの選択肢は、対象キャラクターの技能一覧（白兵・射撃など）から動的に生成される。ハードコードした固定リストではない
- [ ] 実行ボタンを押すと、チャット欄に次の形式の文字列が送信される
      `({能力値}+{DB}+{AdB})DX({クリティカル値})+{技能値}+{AnB}`
      各項は数値に展開する。例: `(4+2+0)DX(9)+3+0`
- [ ] クリティカル値は `10 + AcB` を計算したうえで、**下限 2** を下回る場合は 2 にクランプされる
      （1 にすると全ダイスがクリティカルして無限ロールになるため）

<!-- 当初この条件は `10 - AcB` と書いていたが、AcB はプラグイン内で符号付きの修正値として
     保持されており（クリティカル値を1下げる効果なら AcB = -1）、既存の dx3-combo-box.js も
     `10 + AcB` を採っている。検査でこの食い違いが指摘され、実装ではなく発注書側の誤りと
     ユーザーが裁定したため、条件を `10 + AcB` に訂正した。 -->

- [ ] DB / AdB / AcB / AnB およびクリティカル下限値は、既存の算出ロジック（`js/parameters/dx3.js`、
      `js/parameters/dx3-formula.js`、`js/parameters/dx3-combo-box.js` 等）を流用する。
      同じ計算式を新規に書き直さない
- [ ] チャット送信は既存の送信経路（`js/chat-palette.js` / `js/game-store.js` 等）を流用する。
      新しい送信手段を実装しない
- [ ] 既存の能力値・技能値の表示と編集は従来どおり動作する
- [ ] 能力値または技能値が未選択・未取得の場合でも、例外を投げずに（送信しない等の形で）安全に処理される

## 実装メモ

- UI を足す先は `js/parameters/dx3-ability-box.js`。ボックスの生成・描画はここにある。
- **最初に `js/parameters/dx3-combo-box.js` を読むこと。** 同じプラグイン内で判定式を組み立てて
  チャットに流す既存機能であり、UI の作り方・式の組み立て方・送信方法のすべてがここにある。
  これ1つで方針が立つなら、他は読まなくてよい。
- 判定式の組み立てを関数として切り出す場合は `js/parameters/dx3-formula.js` に置いてよい（ALLOW 済み）。
- CSS が必要な場合のみ `css/character-dialog.css` に追記する。既存セレクタは変更しない。
- クリティカル下限値は `2`。既存コードに同じ役割の定数があればそれを流用し、
  無ければ `2` を定数として定義する（マジックナンバーを式に直書きしない）。

- git commit / git push を実行しない
- 動作に関係ないリファクタや整形をしない
